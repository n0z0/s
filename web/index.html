Written in Rust • Zero RAM Scrollback

The File-Backed Terminal
Session Manager

A middle ground between tmux and dtach. Keeps long-running terminal processes alive with zero memory bloat by persisting scrollback straight to disk.

$ curl -fsSL https://n0z0.if.co.id/s/install.sh | sh
⚡

Extreme Resource Efficiency

Zero scrollback buffer stored in RAM. The server process uses near-zero CPU and negligible memory overhead.

📁

File-Backed Scrollback

All PTY output streams directly to /tmp/s_<session>.log. Inspect live output from anywhere with tail -f.

🛡️

Memory-Safe & Reliable

Engineered in safe Rust using Tokio asynchronous I/O and POSIX Unix Domain Sockets with graceful signal cleanup.

🔄

Dynamic Window Resizing

Full SIGWINCH forwarding ensures editors like Vim, Nano, and modern TUI tools fit your terminal window seamlessly.

🔌

Seamless Detach & Resume

Detach cleanly anytime using Ctrl + \. Sessions persist unaffected through SSH disconnects.

📦

Standalone Static Binary

Compiles to a dependency-free static binary with musl-libc under 2 MB with LTO and size optimization.

Quickstart Guide

# 1. Create or attach to a session named 'main'
s main

# 2. Inside the session, run long tasks (e.g., builds, backups, servers)
npm run build && python worker.py

# 3. Detach cleanly without killing background work
# Press Ctrl + \
[s: detached from session 'main']

# 4. List all active sessions
s list

# 5. Tail output from external tools or scripts
tail -f /tmp/s_main.log

# 6. Re-attach seamlessly anytime
s main
